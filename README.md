# MathSphere — GitHub Pages

Gotowa statyczna strona do wrzucenia na GitHub Pages.

## 1. Utwórz repozytorium
Na GitHubie utwórz publiczne repo, np. `mathsphere`.

## 2. Wrzuć pliki
Wrzuć CAŁĄ zawartość tego folderu do głównego katalogu repozytorium:
- index.html
- cennik.html
- opinie.html
- kontakt.html
- style.css
- script.js
- assets/
- CNAME
- robots.txt
- sitemap.xml
- 404.html

## 3. Włącz GitHub Pages
GitHub -> repo -> Settings -> Pages:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Po chwili strona będzie dostępna pod adresem GitHub Pages.

## 4. Domena mathsphere.eu
Plik `CNAME` jest już przygotowany z domeną `mathsphere.eu`.

Najpierw uruchom stronę na testowym adresie GitHub Pages i sprawdź wszystko.
Dopiero potem zmieniaj rekordy DNS domeny.

## 5. Co warto zrobić przed publicznym startem
- sprawdzić teksty i ewentualnie poprawić brzmienie,
- upewnić się, że można publicznie wykorzystać screeny opinii,
- przetestować stronę na telefonie,
- opcjonalnie dodać Meta Pixel / Google Analytics,
- opcjonalnie dodać politykę prywatności, jeśli włączysz narzędzia śledzące.
